# Cafe Sales Interactive Dashboard

## Overview
This repository contains an interactive business intelligence dashboard built using **Power BI Desktop** for Task 3 of the Swynex Technology Data Analytics Internship. The dashboard provides clear, dynamic insights into cafe operational performance, revenue drivers, sales channel distribution, and payment behavior.

![Power BI Interactive Dashboard](images/dashboard_view.png)

---

## Key Performance Indicators (KPIs)
- **Total Revenue:** $85K
- **Total Orders:** 9,485
- **Average Order Value (AOV):** $8.94
- **Total Units Sold:** 28,636

---

## Core Visualizations & Business Insights
1. **Product Performance (Bar Chart):** Compares total revenue and volume across menu lines, highlighting high-margin food items like Salad and Sandwich as top revenue drivers.
2. **Channel Revenue Share (Donut Chart):** Displays sales distribution between In-store (~50.5%) and Takeaway (~49.5%) orders.
3. **Payment Method Spend Behavior (Column Chart):** Evaluates average transaction spend across verified payment methods (Cash, Credit Card, and Digital Wallet).
4. **POS Logging Quality & Revenue Attribution (Donut Chart):** Tracks system attribution across payment channels to monitor register data logging quality.

---

## Interactive Features & Slicers
- **Location Filter:** Toggle between In-store and Takeaway orders.
- **Payment Method Filter:** Filter dashboard views by Cash, Credit Card, or Digital Wallet.
- **Transaction Date Range:** Dynamic timeline slider to analyze trends across specific date ranges.
- **Cross-Filtering:** Selecting any chart category dynamically filters all visuals and KPI cards on the report page.

---

## Tools Used
- **Power BI Desktop:** DAX measures, visual design, canvas styling, and interactive slicers.
- **Data Source:** Cleaned Cafe Sales Dataset (`.csv`).
